◐ 5 · Slot engine — the only algorithm

lib/slots.ts

getAvailableSlots(dateISO, durationMin) → Slot[] — 30-min steps, respects clinic_hours, blocked_slots, appointments(pending+confirmed), and today+30m buffer.

flowchart LR A[dateISO + durationMin] --> B{clinic_hours
for dow exists
& !is_closed?} B -->|no| Z1[return []] B -->|yes| C[blocked_slots
for date] C --> D{has ALL
null time?} D -->|yes| Z2[return []] D -->|no| E[appointments
pending+confirmed
for date] E --> F[takenTimes Set] F --> G[for m=start; m+durationMin<=end; m+=30] G --> H{blocked or taken
or today && m<=now+30?} H -->|yes| SK[skip] H -->|no| PU[push HH:MM] SK --> G PU --> G G --> OUT[Slot[]]
Known limitation: 60-min service at 09:00 marks only 09:00 taken; 09:30 still shown as free (DB unique index catches exact clash, but interval overlap isn't computed). Fix would be interval intersection.
start = open_time minutes
end   = close_time minutes
for (m=start; m+durationMin<=end; m+=30) {
  time = toHHMM(m)
  if (blocked.has(time) || taken.has(time)) continue
  if (isToday && m <= nowMin+30) continue
  slots.push({time})
}

🌐 11 · i18n & RTL

fr · en · ar

Static JSON import — no CMS fetch.

initI18n() at module load
resources: {fr, en, ar}
fallbackLng: "fr"
detection: [localStorage, navigator]
  caches: [localStorage]
  key: i18nextLng
applyDirection(lang)
if ar → html dir=rtl lang=ar
else   dir=ltr lang=en|fr

localized(obj, field, lang) picks column suffix:

ar → obj[field_ar] || _fr
en → obj[field_en] || _fr
fr → obj[field_fr] || _en

DB columns are tripled: name_fr/name_en/name_ar. Some routes use inline ternaries for pillars.

fmtDate → toLocaleDateString(ar-TN || fr-FR). Fonts: Inter + Noto Sans Arabic, RTL body font switch via html[dir=rtl].
